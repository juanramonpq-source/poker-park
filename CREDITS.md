# Créditos de Poker Park

## Identidad

Poker Park ha sido creado por Pentonúi Games.

Los logotipos e iconos de Pentonúi Games se han incorporado con los recursos facilitados por su titular.

## Audio

La banda sonora y los efectos de Poker Park se generan en tiempo real mediante Web Audio API a partir de composición y código originales incluidos en este repositorio. No contiene pistas musicales de terceros.

## Distribución

Este archivo documenta los créditos de los recursos integrados. La elección de una licencia de software para el código fuente queda reservada a Pentonúi Games.
